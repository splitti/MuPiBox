# Der erste Start

Die Installation der MuPiBox auf eine Speicherkarte beschreibt die Projektwebsite Schritt für Schritt: [Einfache Installation](https://mupibox.de/anleitungen/installationsanleitung/einfache-installation/). Dieses Kapitel beginnt, wenn die Karte in der Box steckt.

## Einschalten

1. Schließe Strom oder Akku an. Die Box fährt hoch und zeigt dabei ein **Startbild** auf dem Display.
2. Nach ein bis zwei Minuten erscheint die Startseite mit den Kategorien ([Die Startseite](../bedienung/startseite.md)).

Das Startbild ist eine von 15 Szenen, die Karte oder jeden Start zufällig. Du wählst es unter **Einstellungen › Aussehen › Start- und Wartungsbilder**. Dasselbe Bild erscheint bei Updates, beim Einrichten eines neuen WLANs und beim Ausschalten, auf Wunsch in einem eigenen Wartungsbild.

## Die Box ins WLAN bringen

Die Box braucht ein WLAN, damit du sie von Handy oder PC aus einrichten kannst und damit Spotify, Podcasts und Radio funktionieren. Wenn sie noch kein Netz kennt, richtest du es am Display ein:

1. Öffne die Einstellungen am Display ([Einstellungen am Display](../bedienung/eltern-zugang.md)).
2. Wähle die **Netzwerkeinstellungen** und dort das WLAN.
3. Tippe dein Netz in der Liste an und gib das Passwort ein.

Die Box bleibt im aktuellen Netz und wechselt erst, wenn das neue erreichbar ist. Mehr dazu, auch zu einer festen IP-Adresse und zum Kabelanschluss: [WLAN und LAN](../netzwerk/wlan-und-lan.md).

## Die Adresse der Box finden

Die Box meldet sich im Netzwerk unter dem Namen `mupibox.local`. Funktioniert das bei dir nicht, brauchst du ihre IP-Adresse. Du findest sie

- auf der Netzwerkseite am Display,
- in der App unter **Einstellungen › Netzwerk › WLAN**,
- in der Geräteliste deines Routers.

## Der Name der Box

Unter **Einstellungen › System › Über die Box** gibst du der Box einen Namen (höchstens 14 Zeichen). Er erscheint im Startbild und auf dem Start der App. Leer lassen heißt: „MuPiBox“. Der Name der Box im Netzwerk (der Hostname) ist etwas anderes und steht unter **Einstellungen › System › Experten**.
