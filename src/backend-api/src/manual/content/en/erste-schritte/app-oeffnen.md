# Opening the app and signing in

The app is the interface for parents. It runs in any browser, on a phone as well as on a PC, and can only be reached in your own network.

## The address

Type the box's address into your browser's address bar, for example:

```
http://mupibox.local/
```

or with the box's IP address:

```
http://192.168.1.50/
```

The box's start page is the app's sign-in window. From there you get into the app and into the box's older admin interface. The app lives at `/app/`, this manual at `/manual/`.

> [!TIP]
> Set a bookmark or put the app on your phone's home screen. With HTTPS set up it can be installed like an app ([Password and HTTPS](../netzwerk/sicherheit.md)).

## Signing in

The app knows several ways in:

- **With a password**, which you set under **Settings › Security › Password & sign-in**. It applies to the whole app, on the phone as on the PC.
- **By QR code on the display**: press and hold the status indicator at the top right of the display for a few seconds (the hold time can be set under **Settings › Display & controls › Controls on the display**). The settings on the display open. Tap **Parent web app** there: a QR code appears that you scan with your phone. This also works without a password ([Settings on the display](../bedienung/eltern-zugang.md)).
- **With a link via Telegram**, if you have set up the bot ([Telegram](../netzwerk/telegram.md)).

If **Require sign-in** is switched on, the box also protects its display page and its interface against access from the network. The box itself, its display and its own services are not affected.

> [!WARNING]
> As long as no password is set and sign-in is not required, anyone in your network can change the box's settings. In a shared network, set a password.

## How the app is organised

| Area | Content |
| --- | --- |
| **Start** | overview and shortcuts |
| **Listen** | what is playing now, [Listening history](../spielzeit/hoer-verlauf.md) |
| **Playtime** | [daily limits, quiet times and sleep timer](../spielzeit/index.md) |
| **Library** | [add and manage content](../inhalte/index.md) |
| **Settings** | everything else, sorted into Appearance, Display & controls, Audio, Battery & Power, Network, Services, Security and System |

## Language

The app speaks 17 languages. **Settings › System › Language** sets the language of the app (“Automatic” follows the browser) and, separately, the language of the box for the texts on the display.
