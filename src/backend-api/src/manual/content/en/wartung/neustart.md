# Restart and shut down

**Settings › System › Restart & shut down**

## The box

| Action | Effect |
| --- | --- |
| **Restart** | restarts the box. This takes about a minute, playback ends |
| **Switch off** | shuts the box down |

> [!NOTE]
> After **switching off**, the box must be switched on again **at the device**: with the on/off button or by briefly disconnecting and reconnecting the power. A switched-off box cannot be started from the app.

## Display and services

Under **Display & services** you restart only parts, without restarting the whole box. That is the quicker way if the display shows an old page or has hung.

| Action | Effect |
| --- | --- |
| **Restart display** | Chromium restarts (a few seconds black). Playback continues |
| **Restart player** | Spotify and local playback restart. Whatever is playing stops |
| **Restart services** | the box's player and server. The app is briefly unreachable |
| **Apply settings** | writes all settings to the services again and restarts the display |

## How the box switches off

A box can go off in several ways: with the app, with the on/off button, with the **sleep timer**, **automatically** after a long silence and when the battery is empty. In every case the same happens: playback stops, the display shows the goodbye picture, a sound plays, the services shut down.

If the box does not go off and hangs, [The box hangs when shutting down](../fehlerbehebung/haengt-beim-ausschalten.md) helps.

> [!WARNING]
> Do not simply pull the plug if you can avoid it. The memory card can be damaged. Switch the box off with the app or the button.
