# Reporting a problem

If something does not work and you cannot get any further, the box collects all the details needed for help and packs them into a single file.

**Settings › System › About the box › Report a problem**

## What goes into the report

The box creates a **zip** with

- the **system state**: version, installation source, hardware, operating system and more,
- the **settings** and the **library**,
- the **end of the logs**.

Not included are **passwords, tokens, accounts, chat IDs, Wi-Fi passwords and MAC addresses**.

> [!IMPORTANT]
> Nothing is sent automatically. The box only downloads the report to your device. You decide who you send it to.

## How to report a problem

1. Under **What is the problem?** write briefly what you did, what happened and what you expected (up to 2000 characters).
2. If it helps, attach **pictures, GIFs or videos**. A photo of the display or a short recording often says more than any description. Up to **5 files** are allowed, each at most 100 MB, 150 MB together.
3. Tap **Create report and download**. Creating it takes a moment.
4. Send the file with your description on, for example in the community's [Discord channel](https://discord.gg/4EjCgpCbbe).

## Report on GitHub

Alternatively **Report on GitHub** opens the project's reporting page. For this you need a **GitHub account**. The page opens with your description, version, hardware and system already filled in, and the report is downloaded. Then:

1. On the GitHub page check the **title** and your description.
2. Attach the downloaded file (`mupibox-report-….zip`): drag it into the text field, on a phone tap **Add files** and choose the file from **Downloads**.
3. At the bottom tap **Submit new issue**.

It is only sent when you submit on GitHub.

## Support information

On the **About the box** page there is also **Download support info**: a file with version, configuration (without passwords) and logs, for when someone asks you for exactly this.
