# Updates

**Settings › System › Updates**

## MuPiBox

The page shows the **installed version** and the available versions in several channels:

| Channel | For whom |
| --- | --- |
| **Stable** | the tested version for everyday use |
| **Beta** | newer features, still being tried out |
| **Dev** | the developer version. At your own risk |

Choose a version and start the update. While it runs, the display shows the maintenance screen ([Covers and themes](../bedienung/cover-und-themes.md)). The box restarts afterwards.

> [!WARNING]
> **Make a backup first** ([Backup](backup.md)). The **developer version can damage the installation.** For an update make sure the box is not interrupted: power and Wi-Fi must hold until the end.

If an update fails, the box restores the previous state.

## News

What is new in each version is under **Settings › System › About the box › News**.

## Operating system

Under **Operating system** you update DietPi, the system underneath the MuPiBox. On older Raspberry Pis this takes **up to 30 minutes**. Do not close the browser and wait for the restart.

> [!WARNING]
> Here too: **always make a backup first.**
