# Using the display

The display is made for the child: big covers, little text, everything with a single tap. This chapter describes what is on the display and how to use it. Parents set all of this up in the [app](../erste-schritte/app-oeffnen.md).

![The start page with Cover Flow](display-home.png)

- [The start page](startseite.md): tabs, how the covers are arranged and the Resume list.
- [The player](player.md): play, skip, track list, output device.
- [Continue and “Now playing”](fortsetzen.md): carry on listening where you left off.
- [Covers and themes](cover-und-themes.md): how the box looks and where the covers come from.
- [Settings on the display](eltern-zugang.md): Wi-Fi, Bluetooth, restart and the QR code for the app, right on the box.
