# Playtime and quiet times

In the app under **Playtime** you decide when and how long the box plays.

| Tool | Purpose |
| --- | --- |
| [Daily limits](tageslimits.md) | how many minutes may be listened to per weekday |
| [Quiet times](ruhezeiten.md) | time windows in which the box stays silent, for example homework and bedtime |
| [Instant actions and sleep timer](schlaftimer.md) | bonus time, lift lock, quiet now, switch off after a time |
| [Listening history](hoer-verlauf.md) | what was listened to in the last days |

## What the child sees

If the limit is used up or a quiet time is running, the display shows a message instead of the player. You change the text under **Settings › Appearance › Text on the display** (the screens “Limit reached”, “Quiet time” and “QR code for parents”). Empty means: the text of the set box language applies.

A small symbol on the display shows the remaining playtime.

## Hearing protection

Independent of time, a **maximum for the volume** limits listening: **Settings › Audio › Volume › Maximum (hearing protection)**. It applies to the display, the app and the rotary knob ([Sound and volume](../hardware/sound.md)).

## Notification

If you have set up the Telegram bot, you get a message when the listening time is used up or a quiet time begins, and a weekly summary on Sundays ([Telegram](../netzwerk/telegram.md)).
