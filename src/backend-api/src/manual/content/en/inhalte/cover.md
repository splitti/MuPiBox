# Covers

Under **Library › Cover** you manage the albums' pictures.

## Custom covers

Under **Custom covers** you upload a picture with **Choose image** and **Upload** (JPG, PNG, GIF or WEBP, 300 to 1200 pixels). A photo that is not square is cropped to a square by the app first. Afterwards you can enter the picture's address as the cover of an item, for example for a radio station that brings no picture of its own. The button next to the picture copies the address, **Delete** removes it.

## Online covers

For albums without a picture of their own, from the NAS or from the memory card, the box can look the cover up online. The cover comes from **iTunes** or **Deezer**, but only for an unambiguous match. The box searches a few minutes after every start and every 6 hours for new folders.

| Setting | Effect |
| --- | --- |
| **Search for cover online** | switches the search on |
| **Also save as cover.jpg in the album folder** | puts found pictures in the folder, but only in folders without a picture. On the NAS the box needs write permission for this |
| **Search discarded ones again too** | also searches albums again whose match you discarded |
| **Search all albums now** | starts the search for the whole library at once |
| **Search again without a match** | repeats the search only for albums where nothing was found |
| **Save remaining found ones** | saves found covers that are not in the album folder yet as cover.jpg afterwards |

> [!IMPORTANT]
> For the search, the **folder names** are sent to Apple (iTunes) and Deezer. If you do not want that, leave **Search for cover online** switched off.

### Wrong cover?

Under **Found covers** you see what the box found, newest first. You can search by album or series and filter by NAS or SD card. A wrong cover can be **discarded**: the album is no longer searched online and falls back to the picture of the folder above it. If the cover was already saved as cover.jpg in the folder, that file is deleted.

## No pictures found

If an album stays without a picture, the box shows the theme's placeholder picture ([Covers and themes](../bedienung/cover-und-themes.md)).
