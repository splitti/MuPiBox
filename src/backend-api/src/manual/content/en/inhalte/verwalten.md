# Managing content

What is already on the box is managed under **Library › Managed items** and on the **Library** page.

## Artist subscriptions

An **artist subscription** fetches all albums of an artist, such as a series of radio plays. For each subscription you set:

- **Episode from / Episode to**: only a range of episodes, for example 1 to 80,
- single episodes that you **exclude**: their switch is set to “excluded”.

With **Apply** you save the changes, with **Remove subscription** you delete the subscription.

## Single albums

Albums added one by one are in the **Single albums** list and can be removed there again.

## Do not forget the backup

The list of content, the covers and the configuration are in the **configuration backup** ([Backup](../wartung/backup.md)). Make one before larger changes.
