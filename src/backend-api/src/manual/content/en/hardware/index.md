# Hardware and accessories

This chapter describes how you connect the display, sound and accessories to the box and set them up in the app.

| Page | Content |
| --- | --- |
| [Display](display.md) | brightness, display off, rotation, resolution |
| [Sound and volume](sound.md) | sound card, maximum, start volume |
| [Rotary knob and button](drehregler.md) | volume and track selection with a rotary knob |
| [Battery, MuPiHAT and power button](strom.md) | battery profile, automatic shutdown, on/off button, LED |
| [Fan](luefter.md) | temperature-controlled fan |
| [Bluetooth](bluetooth.md) | pair headphones and speakers |
| [WLED](wled.md) | light strip with light effects |

> [!WARNING]
> Accessories that are connected to the Raspberry Pi's GPIO pins must not share pins. Which pins the box uses by default is listed in the [appendix](../anhang/gpio.md). The app warns you if you choose a pin for an accessory that another one already uses.
