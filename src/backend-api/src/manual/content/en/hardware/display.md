# Display

**Settings › Display & controls › Display**

## Brightness and display off

| Setting | Range |
| --- | --- |
| **Brightness** | 0 to 100 % |
| **Display off after** | 0 to 120 minutes, **0 = never** (10 minutes after installation) |

The display switches itself off after the set time without use, the box itself keeps running. A tap on the screen wakes it up again.

## Rotation

If the display stands upside down or sideways, you rotate the picture: **HDMI rotation** (off, 90°, 180°, 270°, mirror horizontally or vertically) for HDMI displays, **LCD rotation** and **Display LCD rotation** (off or 180°) for LCD displays that sit directly on the Pi. The rotation is applied after a restart.

## Resolution

The default is **800 × 480** pixels (the size of the usual 7-inch touch displays). If your display has a different resolution, enter **width** and **height**. Background pictures for the theme “custom” fit best at exactly this size ([Covers and themes](../bedienung/cover-und-themes.md)).

## Live display

Under **Settings › Display & controls › Live display** you see the display's current picture (it refreshes every few seconds) and can **remote-control** the display in the browser. The remote control needs VNC ([Shares and remote control](../netzwerk/freigaben.md)).

## Browser settings

The display is a browser in full-screen mode (Chromium). Its settings, such as GPU support and cache, are under **Settings › System › Browser (Chromium)** ([System and expert settings](../wartung/system.md)).
