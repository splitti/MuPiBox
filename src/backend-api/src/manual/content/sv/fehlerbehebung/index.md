# Felsökning

Om något inte fungerar, leta här efter tecknet du ser.

| Problem | Sida |
| --- | --- |
| Boxen spelar, men inget hörs | [Inget ljud](kein-ton.md) |
| Appen går inte att öppna | [Appen går inte att nå](app-nicht-erreichbar.md) |
| Spotify-innehåll startar inte | [Spotify spelar inte](spotify-probleme.md) |
| Boxen hänger sig vid avstängning | [Boxen hänger sig vid avstängning](haengt-beim-ausschalten.md) |
| Wi-Fi-symbolen saknas, displayen är mörk, uppdatering och mer | [Fler fall](weitere-faelle.md) |

## Om inget av det hjälper

1. Titta i **Lådans status** och i loggarna ([Loggar och status](../wartung/protokolle.md)).
2. Ladda ner under **Inställningar › System › Om boxen** **supportinfo**: version, inställningar utan lösenord, bibliotek samt nätverks- och systemläge i en fil. Loggar ingår inte, dem laddar du till under **Loggar**.
3. Fråga i communityn: [Discord](https://discord.gg/4EjCgpCbbe) eller [mupibox.de](https://mupibox.de). Ett fel kan du också rapportera på GitHub: [splitti/MuPiBox](https://github.com/splitti/MuPiBox/issues).

> [!TIP]
> En omstart av boxen ([Starta om och stäng av](../wartung/neustart.md)) löser förvånansvärt många problem. Ta dock först en [säkerhetskopia](../wartung/backup.md) om du har ändrat något i konfigurationen.
