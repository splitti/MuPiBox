# Ordlista

| Begrepp | Betydelse |
| --- | --- |
| **App** | gränssnittet för föräldrar som körs i webbläsaren (`/app/`) |
| **Broker** | servern som vid MQTT tar emot och fördelar meddelanden |
| **Omslag (Cover)** | bilden för ett album, en podd eller en kanal |
| **Cover Flow** | vyn där ett stort omslag ligger i mitten och grannarna står snett |
| **DHCP** | metod där routern tilldelar en enhet en IP-adress |
| **DietPi** | den smala Linux-distribution som MuPiBox körs på |
| **Display** | boxens pekskärm där barnet styr |
| **DAC** | komponent som omvandlar digital musik till ljud (ett ljudkort för Raspberry Pi) |
| **FTP** | metod för att kopiera filer via nätverket |
| **GPIO** | anslutningsstiften på Raspberry Pi där tillbehör sitter |
| **Värdnamn (Hostname)** | boxens namn i nätverket, till exempel `mupibox` (nåbar som `mupibox.local`) |
| **HTTPS** | krypterad anslutning till appen |
| **IP-adress** | boxens adress i nätverket |
| **Kioskläge** | helskärm utan webbläsarens kontroller, så körs displayen |
| **MQTT** | en lätt meddelandemetod för smarta hem och enheter |
| **mpv** | programmet som spelar ljudböcker, musik, poddar och radio |
| **MuPiHAT** | kretskort med batterihantering för boxen |
| **NAS** | nätverkslagring i hemnätverket |
| **OnOff SHIM** | på/av-knapp med drift-LED för Raspberry Pi |
| **Overlay** | en hårdvarubeskrivning som Raspberry Pi läser in vid start från `/boot/config.txt` |
| **PM2** | program som övervakar servern och spelaren och startar om dem |
| **Spellisteprefix** | namnets början som Smart-Sync känner igen boxens Spotify-spellistor på |
| **RSS** | formatet i vilket poddar publicerar sina avsnitt |
| **Vilotid** | tidsfönster då boxen inte spelar |
| **Samba** | metod som får boxens mediemapp (`/home/dietpi/MuPiBox/media`) att visas som en enhet i Windows-nätverket |
| **Smart-Sync** | hämtar Spotify-spellistor automatiskt till boxen |
| **Spotify-spelare** | Spotify spelar i displayens webbläsare (Spotify Web Playback SDK med Widevine). För Spotify är displayen enheten som boxen spelar på |
| **SSID** | namnet på ett Wi-Fi-nätverk |
| **Tema (Theme)** | displayens utseende: färger, bakgrunder, typsnitt |
| **Token** | en hemlig nyckel som en tjänst (till exempel en Telegram-bot) legitimerar sig med |
| **VNC** | fjärrstyrning av skärmen via nätverket |
| **WLED** | styrning för ljusslingor som boxen kan förbindas med för ljuseffekter |
