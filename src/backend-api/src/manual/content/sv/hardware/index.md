# Hårdvara och tillbehör

Det här kapitlet beskriver hur du ansluter display, ljud och tillbehör till boxen och ställer in dem i appen.

| Sida | Innehåll |
| --- | --- |
| [Display](display.md) | displaymodell, ljusstyrka, mörkare på kvällen, display av, vridning, upplösning |
| [Ljud och volym](sound.md) | ljudkort, maximum, startvolym, jämna ut volymen |
| [Vridratt och knapp](drehregler.md) | volym och spårval med en vridratt |
| [Batteri, MuPiHAT och strömbrytare](strom.md) | batteriprofil, automatisk avstängning, på/av-knapp, LED |
| [Fläkt](luefter.md) | temperaturstyrd fläkt |
| [Bluetooth](bluetooth.md) | parkoppla hörlurar och högtalare |
| [WLED](wled.md) | ljusslinga med ljuseffekter |

> [!WARNING]
> Tillbehör som ansluts till Raspberry Pi:s GPIO-stift får inte dela på stiften. Vilka stift boxen använder som standard står i [bilagan](../anhang/gpio.md). Appen varnar om du för ett tillbehör väljer ett stift som ett annat redan använder.
