# Lyssningshistorik

Under **Lyssna › Lyssningshistorik** ser du vad boxen har spelat, så att du vet hur mycket och vad som lyssnas på.

| Område | Innehåll |
| --- | --- |
| **I dag** | dagens lyssningstid, hur många spår som har spelats och vad som lyssnats mest på |
| **Senaste 7 dagarna** | lyssningstiden per dag som diagram, dessutom summan i minuter och spår |
| **Mest lyssnat (7 dagar)** | albumen eller artisterna med flest minuter och hur ofta de spelades |
| **Topplåtar (7 dagar)** | de enskilda spår som lyssnats på oftast |

> [!TIP]
> Vill du slippa slå upp siffrorna, slå på **veckosammanfattningen** i Telegram-boten: den skickar dig på söndagskvällen hur länge och vad som lyssnats på under veckan ([Telegram](../netzwerk/telegram.md)).
