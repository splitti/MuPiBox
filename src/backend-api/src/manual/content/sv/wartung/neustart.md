# Starta om och stäng av

**Inställningar › System › Starta om & stäng av**

## Boxen

| Åtgärd | Verkan |
| --- | --- |
| **Starta om** | startar om boxen. Det tar ungefär en minut, uppspelningen tar slut |
| **Stäng av** | stänger ned boxen |

> [!NOTE]
> Efter **avstängning** måste boxen slås på igen **på enheten**: med på/av-knappen eller genom att kort koppla från och återansluta strömmen. Från appen går en avstängd box inte att starta.

## Display och tjänster

Under **Display & tjänster** startar du bara om delar, utan att starta om hela boxen. Det är den snabbare vägen när displayen visar en gammal sida eller har hängt sig.

| Åtgärd | Verkan |
| --- | --- |
| **Starta om display** | Chromium startar om (några sekunder svart). Uppspelningen fortsätter |
| **Starta om spelaren** | Spotify och den lokala uppspelningen startar om. Det som spelas stoppar |
| **Starta om tjänster** | boxens spelare och server. Appen går då kort inte att nå |
| **Tillämpa inställningar** | skriver alla inställningar på nytt till tjänsterna och startar om displayen |

## Så stänger boxen av sig

En box kan stängas av på flera sätt: med appen, med på/av-knappen, med **insomningstimern**, **automatiskt** efter lång tystnad och vid tomt batteri. Vid varje sätt går samma sak till: Uppspelningen stoppar, displayen visar avskedsbilden, en ton ljuder, tjänsterna stängs ned.

Stängs boxen inte av utan hänger sig hjälper [Boxen hänger sig vid avstängning](../fehlerbehebung/haengt-beim-ausschalten.md).

> [!WARNING]
> Dra inte bara ur kontakten om du kan undvika det. Minneskortet kan ta skada. Stäng av boxen via appen eller knappen.
