# Tillägg

Sedan MuPiBox 5.1 går det att installera **tillägg** i efterhand: extrafunktioner som inte varje box behöver. Boxen är komplett även utan dem. De installeras, slås på och av och tas bort i appen under **Inställningar › System › Tillägg**.

| Sida | Innehåll |
| --- | --- |
| [Installera och hantera](installieren.md) | Katalog, installera, slå på och av, ta bort, egna filer |
| [Buttons & GPIO Input](buttons.md) | Knappar på GPIO-stiften styr boxen: kort och långt tryck, dubbelknapp |
| [USB-CD-enhet](cd-laufwerk.md) | Spela ljud-cd-skivor från en USB-enhet |
| [Media-Control](media-control.md) | en rund kontroll ersätter knapparna i spelaren: volym, spår, spolning med låsning, tre utseenden |
| [Klockan i sidhuvudet](uhrzeit.md) | klockan överst på displayen, digital eller analog |
| [Väder](wetter.md) | vädret på en ort som mätare på displayen |
| [Fotboll](fussball.md) | din egen klubb, omgången och tabellen på displayen |
| [NFC-tillägg](nfc.md) | upp till tre NFC-läsare (PN5180, RC522, PN532, USB) startar media med taggar: tilldela taggar, ansluta läsare, kopplingar |

> [!WARNING]
> Ett tillägg är ett program som körs på boxen **utan skydd**. Installera bara tillägg från katalogen eller från källor du litar på.
