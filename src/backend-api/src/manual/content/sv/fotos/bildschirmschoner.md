# Skärmsläckare

Skärmsläckaren visar ett bildspel av de synliga albumen när ingen gör något vid boxen på en stund. Du slår på den under **Inställningar › Foton › Skärmsläckare**.

| Inställning | Verkan |
| --- | --- |
| **Skärmsläckare** | på eller av |
| **Startar efter** | efter hur många minuter utan beröring (1 till 30, från början 5) |
| **Även under uppspelning** | körs även när ett hörspel eller musik spelas; annars bara när boxen är tyst |

- Ett tryck avslutar skärmsläckaren. Trycket utlöser då inget annat.
- Den slutar av sig själv när displayen släcks som vanligt (**Inställningar › Display & manövrering › Display**). Den håller inte displayen tänd längre.
- Den räknas inte som [bildtid](bildzeit.md). Den körs inte under vilotider och inte när bildtiden för i dag är slut.
- Klipp visar den inte, bara foton.
