# Nätverk och fjärråtkomst

Boxen arbetar i hemnätverket. Det här kapitlet visar hur du ansluter den och når den säkert utifrån.

| Sida | Innehåll |
| --- | --- |
| [Wi-Fi och LAN](wlan-und-lan.md) | anslutning, flera nät, fast IP-adress, kabel |
| [Delade resurser och fjärrstyrning](freigaben.md) | Samba, FTP och VNC |
| [Lösenord och HTTPS](sicherheit.md) | skydda appen, krypterad anslutning |
| [Telegram](telegram.md) | föräldrabot med meddelanden och fjärrkontroll |
| [MQTT](mqtt.md) | status och kommandon via en MQTT-broker, med MQTT-Discovery |
| [Home Assistant](home-assistant.md) | visa och styra via boxens Home Assistant-gränssnitt |

> [!NOTE]
> Boxen är tänkt för **hemnätverket**. Gör den inte direkt nåbar från internet. Den som vill komma åt den på resa använder ett VPN.
