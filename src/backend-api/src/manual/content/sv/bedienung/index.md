# Använda displayen

Displayen är gjord för barnet: stora omslag, lite text, allt med ett tryck. Det här kapitlet beskriver vad som syns på displayen och hur den används. Föräldrar ställer in allt det här i [appen](../erste-schritte/app-oeffnen.md).

![Startsidan med Cover Flow](display-home.png)

- [Startsidan](startseite.md): flikar, omslagens ordning och Fortsätt-listan.
- [Spelaren](player.md): spela, hoppa, spårlista, utgångsenhet.
- [Fortsätt och ”Körs just nu”](fortsetzen.md): lyssna vidare där det tog stopp.
- [Omslag och teman](cover-und-themes.md): hur boxen ser ut och var omslagen kommer ifrån.
- [Winamp-temat](winamp.md): spelaren i den klassiska Winamps utseende, med skal, equalizer och spellista.
- [Inställningar på displayen](eltern-zugang.md): ställa in Wi-Fi, Bluetooth, omstart och QR-koden för appen, direkt på boxen.
