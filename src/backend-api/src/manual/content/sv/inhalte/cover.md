# Omslag

Under **Bibliotek › Omslag** hanterar du albumens bilder.

## Egna omslag

Under **Egna omslag** laddar du med **Välj bild** och **Ladda upp** upp en bild (JPG, PNG, GIF eller WEBP, 300 till 1200 pixlar). Ett foto som inte är kvadratiskt beskär appen först till kvadrat. Bildens adress kan du sedan ange som omslag vid ett innehåll, till exempel vid en radiokanal som inte har någon egen bild. Knappen bredvid bilden kopierar adressen, **Radera** tar bort den.

## Onlineomslag

Album utan egen bild, från NAS eller från minneskortet, kan boxen slå upp online. Omslaget kommer från **iTunes** eller **Deezer**, men bara vid en entydig träff. Boxen söker ett par minuter efter varje start och var 6:e timme efter nya mappar.

| Inställning | Verkan |
| --- | --- |
| **Sök omslag online** | slår på sökningen |
| **Spara även som cover.jpg i albummappen** | lägger hittade bilder i mappen, men bara i mappar utan bild. På NAS:en behöver boxen skrivrättighet för det |
| **Sök även om förkastade** | söker än en gång även album vars träff du har förkastat |
| **Sök alla album nu** | startar sökningen direkt för hela biblioteket |
| **Sök igen utan träff** | upprepar sökningen bara för album där inget hittades |
| **Spara övriga hittade** | sparar hittade omslag som ännu inte ligger i albummappen i efterhand som cover.jpg |

> [!IMPORTANT]
> För sökningen skickas **mappnamnen** till Apple (iTunes) och Deezer. Den som inte vill det låter **Sök omslag online** vara avstängt.

### Fel omslag?

Under **Hittade omslag** ser du vad boxen har hittat, de nyaste först. Du kan söka efter album eller serie och filtrera efter NAS eller SD-kort. Ett felaktigt omslag kan du **förkasta**: albumet söks då inte längre online och faller tillbaka på bilden i mappen ovanför. Låg omslaget redan som cover.jpg i mappen raderas den filen.

## Inga bilder hittades

Förblir ett album utan bild visar boxen temats reservbild ([Omslag och teman](../bedienung/cover-und-themes.md)).
