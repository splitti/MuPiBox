# Spielzeit und Ruhezeiten

In der App unter **Spielzeit** bestimmst du, wann und wie lange die Box spielt.

| Werkzeug | Wofür |
| --- | --- |
| [Tageslimits](tageslimits.md) | wie viele Minuten pro Wochentag gehört werden darf |
| [Ruhezeiten](ruhezeiten.md) | Zeitfenster, in denen die Box schweigt, zum Beispiel Hausaufgaben und Schlafenszeit |
| [Sofort-Aktionen und Schlaftimer](schlaftimer.md) | Bonus-Zeit, Sperren aufheben, sofort Ruhe, Ausschalten nach Zeit |
| [Hör-Verlauf](hoer-verlauf.md) | was in den letzten Tagen gehört wurde |

## Was das Kind sieht

Ist das Limit aufgebraucht oder läuft eine Ruhezeit, erscheint auf dem Display ein Hinweis statt des Players. Den Text änderst du unter **Einstellungen › Aussehen › Texte auf dem Display** (Bildschirme „Limit erreicht“, „Ruhezeit“ und „QR-Code für Eltern“). Leer heißt: Der Text der eingestellten Box-Sprache gilt.

Ein kleines Symbol auf dem Display zeigt die verbleibende Spielzeit an.

## Hörschutz

Unabhängig von der Zeit begrenzt ein **Maximum für die Lautstärke** das Hören: **Einstellungen › Audio › Lautstärke › Maximum (Hörschutz)**. Er gilt für Display, App und Drehregler ([Sound und Lautstärke](../hardware/sound.md)).

## Benachrichtigung

Wer den Telegram-Bot eingerichtet hat, bekommt eine Nachricht, wenn die Hörzeit aufgebraucht ist oder eine Ruhezeit beginnt, und sonntags einen Wochenrückblick ([Telegram](../netzwerk/telegram.md)).
