# Tageslimits

Mit Tageslimits legst du fest, wie viele Minuten pro Wochentag gehört werden darf. Sie stehen unter **Spielzeit › Tageslimits**.

## Einstellen

1. Schalte **Tageslimits aktiv** ein.
2. Trage für jeden Wochentag die **Minuten** ein. **0 bedeutet: an diesem Tag gesperrt.**
3. Lege fest, wann ein neuer Tag beginnt (**Tageswechsel um**): Eine Stunde von 0 bis 23. Mit 4 zum Beispiel zählt spätes Hören nach Mitternacht noch zum Vortag, und die Wiedergabe bricht nicht mittendrin ab.

Das Limit zählt die Zeit, in der tatsächlich abgespielt wird.

## Was passiert beim Limit?

Die Einstellung **Wenn das Limit erreicht ist** bestimmt es:

| Wahl | Wirkung |
| --- | --- |
| **Sofort stoppen** | die Wiedergabe endet auf der Stelle |
| **Titel zu Ende spielen** | der laufende Titel wird zu Ende gespielt |
| **Album zu Ende spielen** | das laufende Album wird zu Ende gespielt |

Damit ein Hörspiel nicht endlos weiterläuft, begrenzt **Höchstens so lange weiterspielen** die Nachspielzeit (5 Minuten bis 3 Stunden). Danach stoppt die Box auch mitten im Titel oder Album.

> [!NOTE]
> **Podcasts** dürfen die Folge beenden. **Radio** stoppt sofort, denn ein Radiosender hat kein Ende.

## Ausnahmen

Möchtest du für heute mehr Zeit geben oder die Sperre kurz aufheben, nimm die [Sofort-Aktionen](schlaftimer.md). Sie ändern das Tageslimit nicht dauerhaft.
