# Display

**Einstellungen › Display & Bedienung › Display**

## Helligkeit und Display-Aus

| Einstellung | Bereich |
| --- | --- |
| **Helligkeit** | 0 bis 100 % |
| **Display aus nach** | 0 bis 120 Minuten, **0 = nie** (nach der Installation 10 Minuten) |

Das Display schaltet sich nach der eingestellten Zeit ohne Bedienung aus, die Box selbst läuft weiter. Ein Tipp auf den Bildschirm weckt es wieder.

## Drehung

Steht das Display auf dem Kopf oder quer, drehst du das Bild: **HDMI-Drehung** (aus, 90°, 180°, 270°, horizontal oder vertikal spiegeln) für HDMI-Displays, **LCD-Drehung** und **Display-LCD-Drehung** (aus oder 180°) für LCD-Displays, die direkt am Pi sitzen. Die Drehung wird nach einem Neustart übernommen.

## Auflösung

Der Standard ist **800 × 480** Pixel (die Größe der üblichen 7-Zoll-Touch-Displays). Hat dein Display eine andere Auflösung, trägst du **Breite** und **Höhe** ein. Hintergrundbilder für das Theme „custom“ passen am besten in genau dieser Größe ([Cover und Themes](../bedienung/cover-und-themes.md)).

## Display live

Unter **Einstellungen › Display & Bedienung › Display live** siehst du das aktuelle Bild des Displays (es aktualisiert sich alle paar Sekunden) und kannst das Display im Browser **fernsteuern**. Die Fernsteuerung braucht VNC ([Freigaben und Fernsteuerung](../netzwerk/freigaben.md)).

## Browser-Einstellungen

Das Display ist ein Browser im Vollbildmodus (Chromium). Dessen Einstellungen, etwa GPU-Unterstützung und Cache, findest du unter **Einstellungen › System › Browser (Chromium)** ([System- und Experteneinstellungen](../wartung/system.md)).
