# Netzwerk und Fernzugriff

Die Box arbeitet im Heimnetz. Dieses Kapitel zeigt, wie du sie verbindest und von außen sicher erreichst.

| Seite | Inhalt |
| --- | --- |
| [WLAN und LAN](wlan-und-lan.md) | Verbindung, mehrere Netze, feste IP-Adresse, Kabel |
| [Freigaben und Fernsteuerung](freigaben.md) | Samba, FTP und VNC |
| [Passwort und HTTPS](sicherheit.md) | die App schützen, verschlüsselte Verbindung |
| [Telegram](telegram.md) | Eltern-Bot mit Benachrichtigungen und Fernbedienung |
| [MQTT](mqtt.md) | Zustand und Befehle über einen MQTT-Broker, mit MQTT-Discovery |
| [Home Assistant](home-assistant.md) | anzeigen und steuern über die Home-Assistant-Schnittstelle der Box |

> [!NOTE]
> Die Box ist für das **Heimnetz** gedacht. Mache sie nicht unmittelbar aus dem Internet erreichbar. Wer von unterwegs zugreifen will, nimmt dafür ein VPN.
