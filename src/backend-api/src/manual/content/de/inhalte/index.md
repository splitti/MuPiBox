# Inhalte hinzufügen

Alles, was die Box abspielt, verwaltest du in der App im Bereich **Bibliothek**. Es gibt vier Wege, Inhalte auf die Box zu bringen:

| Quelle | Wann sinnvoll | Seite |
| --- | --- | --- |
| **Eigene Dateien** | Hörspiel-CDs, gekaufte Musik, selbst Aufgenommenes | [Eigene Hörspiele und Musik](lokale-medien.md) |
| **Spotify** | Alben, Playlists, Künstler, Hörbücher und Podcasts von Spotify | [Spotify](spotify.md) |
| **Podcasts und Radio** | RSS-Podcasts und Internetradio | [Podcasts und Radio](podcasts-und-radio.md) |
| **NAS** | Medien auf einem Netzwerkspeicher im Heimnetz | [NAS](nas.md) |

Jeder Inhalt kommt in eine **Kategorie**: Hörbuch, Hörspiel, Musik oder Radio & Podcasts. Die Kategorie bestimmt, unter welchem Reiter er auf dem Display erscheint ([Die Startseite](../bedienung/startseite.md)).

Danach:

- [Cover](cover.md): eigene Bilder, Online-Cover und was bei fehlenden Covern passiert.
- [Inhalte verwalten](verwalten.md): Künstler-Abos, einzelne Alben ausschließen, entfernen.

> [!TIP]
> Neue Inhalte erscheinen von selbst auf dem Display. Ein Neustart ist nicht nötig.
