# Glossar

| Begriff | Bedeutung |
| --- | --- |
| **App** | die Oberfläche für Eltern, die im Browser läuft (`/app/`) |
| **Broker** | der Server, der bei MQTT Nachrichten entgegennimmt und verteilt |
| **Cover** | das Bild eines Albums, Podcasts oder Senders |
| **Cover Flow** | die Ansicht, in der ein großes Cover in der Mitte liegt und die Nachbarn schräg gestellt sind |
| **DHCP** | Verfahren, bei dem der Router einem Gerät eine IP-Adresse zuteilt |
| **DietPi** | das schlanke Linux, auf dem die MuPiBox läuft |
| **Display** | der Touch-Bildschirm der Box, auf dem das Kind bedient |
| **DAC** | Baustein, der digitale Musik in Ton umwandelt (eine Soundkarte für den Raspberry Pi) |
| **FTP** | Verfahren zum Kopieren von Dateien über das Netzwerk |
| **GPIO** | die Anschlusspins des Raspberry Pi, an denen Zubehör hängt |
| **Hostname** | der Name der Box im Netzwerk, zum Beispiel `mupibox` (erreichbar als `mupibox.local`) |
| **HTTPS** | verschlüsselte Verbindung zur App |
| **IP-Adresse** | die Adresse der Box im Netzwerk |
| **Kiosk-Modus** | Vollbild ohne Bedienelemente des Browsers, so läuft das Display |
| **Librespot** | der freie Spotify-Connect-Baustein, den die Box verwendet |
| **MQTT** | ein leichtes Nachrichtenverfahren für Smarthome und Geräte |
| **MuPiHAT** | Platine mit Akku-Verwaltung für die Box |
| **NAS** | Netzwerkspeicher im Heimnetz |
| **OnOff SHIM** | Ein-/Aus-Taster mit Betriebs-LED für den Raspberry Pi |
| **Overlay** | eine Hardware-Beschreibung, die der Raspberry Pi beim Start in `/boot/config.txt` lädt |
| **PM2** | Programm, das den Server und den Player überwacht und neu startet |
| **Playlist-Präfix** | der Namensanfang, an dem Smart-Sync die Spotify-Playlists der Box erkennt |
| **RSS** | das Format, in dem Podcasts ihre Folgen veröffentlichen |
| **Ruhezeit** | Zeitfenster, in dem die Box nicht spielt |
| **Samba** | Verfahren, mit dem die Speicherkarte im Windows-Netzwerk als Laufwerk erscheint |
| **Smart-Sync** | holt Spotify-Playlists automatisch auf die Box |
| **SSID** | der Name eines WLAN-Netzes |
| **Theme** | Aussehen des Displays: Farben, Hintergründe, Schriften |
| **Token** | ein geheimer Schlüssel, mit dem sich ein Dienst (zum Beispiel ein Telegram-Bot) ausweist |
| **VNC** | Fernsteuerung des Bildschirms über das Netzwerk |
| **WLED** | Steuerung für Leuchtstreifen, die die Box mit Lichteffekten verbinden kann |
