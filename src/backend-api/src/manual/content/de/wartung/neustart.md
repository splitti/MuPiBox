# Neu starten und Ausschalten

**Einstellungen › System › Neu starten & Ausschalten**

## Die Box

| Aktion | Wirkung |
| --- | --- |
| **Neu starten** | startet die Box neu. Das dauert etwa eine Minute, die Wiedergabe endet |
| **Ausschalten** | fährt die Box herunter |

> [!NOTE]
> Nach dem **Ausschalten** muss die Box **am Gerät** wieder eingeschaltet werden: mit dem Ein-/Aus-Taster oder durch kurzes Trennen und Wiederanschließen des Stroms. Aus der App lässt sich eine ausgeschaltete Box nicht starten.

## Display und Dienste

Unter **Display & Dienste** startest du nur Teile neu, ohne die ganze Box neu zu starten. Das ist der schnellere Weg, wenn das Display eine alte Seite zeigt oder sich aufgehängt hat.

| Aktion | Wirkung |
| --- | --- |
| **Display neu starten** | Chromium startet neu (ein paar Sekunden schwarz). Die Wiedergabe läuft weiter |
| **Player neu starten** | Spotify und die lokale Wiedergabe starten neu. Was läuft, stoppt |
| **Dienste neu starten** | Player und Server der Box. Die App ist dabei kurz nicht erreichbar |
| **Einstellungen übernehmen** | schreibt alle Einstellungen neu in die Dienste und startet das Display neu |

## So schaltet sich die Box aus

Eine Box kann auf mehreren Wegen ausgehen: mit der App, mit dem Ein-/Aus-Taster, mit dem **Schlaftimer**, **automatisch** nach langer Stille und bei leerem Akku. Bei jedem Weg läuft dasselbe ab: Die Wiedergabe stoppt, das Display zeigt das Abschiedsbild, ein Ton erklingt, die Dienste fahren herunter.

Geht die Box nicht aus und bleibt hängen, hilft [Die Box hängt beim Ausschalten](../fehlerbehebung/haengt-beim-ausschalten.md).

> [!WARNING]
> Ziehe nicht einfach den Stecker, wenn du es vermeiden kannst. Die Speicherkarte kann dabei Schaden nehmen. Schalte die Box über die App oder den Taster aus.
