# Ein Problem melden

Wenn etwas nicht funktioniert und du nicht weiterkommst, sammelt die Box für dich alle Angaben, die man zur Hilfe braucht, und packt sie in eine einzige Datei.

**Einstellungen › System › Über die Box › Problem melden**

## Was in den Bericht kommt

Die Box erstellt ein **Zip** mit

- dem **Systemstand**: Version, Installationsquelle, Hardware, Betriebssystem und mehr,
- den **Einstellungen** und der **Bibliothek**,
- dem **Ende der Logs**.

Nicht enthalten sind **Passwörter, Tokens, Konten, Chat-IDs, WLAN-Passwörter und MAC-Adressen**.

> [!IMPORTANT]
> Nichts wird automatisch gesendet. Die Box lädt den Bericht nur auf dein Gerät herunter. Du entscheidest, wem du ihn schickst.

## So meldest du ein Problem

1. Schreibe unter **Was ist das Problem?** kurz auf, was du getan hast, was passiert ist und was du erwartet hast (bis zu 2000 Zeichen).
2. Hänge, wenn es hilft, **Bilder, GIFs oder Videos** an. Ein Foto vom Display oder eine kurze Aufnahme sagt oft mehr als jede Beschreibung. Erlaubt sind bis zu **5 Dateien**, je höchstens 100 MB, zusammen 150 MB.
3. Tippe auf **Bericht erstellen und herunterladen**. Das Erstellen dauert einen Moment.
4. Schicke die Datei mit deiner Beschreibung weiter, zum Beispiel im [Discord-Kanal](https://discord.gg/4EjCgpCbbe) der Community.

## Auf GitHub melden

Alternativ öffnet **Auf GitHub melden** die Meldeseite des Projekts. Dafür brauchst du ein **GitHub-Konto**. Die Seite öffnet sich mit deiner Beschreibung, Version, Hardware und System bereits ausgefüllt, und der Bericht wird heruntergeladen. Danach:

1. Prüfe auf der GitHub-Seite den **Titel** und deine Beschreibung.
2. Hänge die heruntergeladene Datei (`mupibox-report-….zip`) an: in das Textfeld ziehen, am Handy **Add files** antippen und die Datei aus **Downloads** wählen.
3. Tippe unten auf **Submit new issue**.

Gesendet wird erst, wenn du auf GitHub abschickst.

## Support-Informationen

Auf der Seite **Über die Box** gibt es außerdem **Support-Infos herunterladen**: Eine Datei mit Version, Konfiguration (ohne Passwörter) und Logs, wenn dich jemand um genau diese Angaben bittet.
