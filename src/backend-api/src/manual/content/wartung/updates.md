# Updates

**Einstellungen › System › Updates**

## MuPiBox

Die Seite zeigt die **installierte Version** und die verfügbaren Versionen in mehreren Kanälen:

| Kanal | Für wen |
| --- | --- |
| **Stable** | die geprüfte Version für den Alltag |
| **Beta** | neuere Funktionen, noch in der Erprobung |
| **Dev** | die Entwicklerversion. Auf eigenes Risiko |

Wähle eine Version aus und starte das Update. Während es läuft, zeigt das Display das Wartungsbild ([Cover und Themes](../bedienung/cover-und-themes.md)). Die Box startet danach neu.

> [!WARNING]
> **Mache vorher ein Backup** ([Backup](backup.md)). Die **Entwicklerversion kann die Installation beschädigen.** Stelle bei einem Update sicher, dass die Box nicht unterbrochen wird: Strom und WLAN müssen bis zum Ende halten.

Schlägt ein Update fehl, stellt die Box den vorherigen Stand wieder her.

## Neuigkeiten

Was in der jeweiligen Version neu ist, steht unter **Einstellungen › System › Über die Box › Neuigkeiten**.

## Betriebssystem

Unter **Betriebssystem** aktualisierst du DietPi, das System unter der MuPiBox. Das dauert auf älteren Raspberry Pis **bis zu 30 Minuten**. Schließe den Browser nicht und warte auf den Neustart.

> [!WARNING]
> Auch hier gilt: **Vorher immer ein Backup machen.**
