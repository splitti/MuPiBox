**MuPiBox Classic** est la génération précédente du lecteur de musique. Son installation, son administration et ses commandes diffèrent de MuPiBox NG. **N’utilisez pas** les instructions NG pour un boîtier Classic.

## Lire le guide Classic

Les instructions actuelles se trouvent sur [mupibox.de – Guides Classic](https://mupibox.de/anleitungen/classic/). Le guide externe n’est pas nécessairement disponible dans toutes les langues.

## À venir sur ce site

Les chapitres Classic dédiés à l’installation, à la configuration, aux services musicaux, au matériel et à la maintenance arriveront sous `docs.mupibox.de/classic/fr/`. La documentation NG sous `/ng/` restera indépendante.

## Vous utilisez MuPiBox NG ?

Consultez le [guide de MuPiBox NG](https://docs.mupibox.de/ng/fr/).
