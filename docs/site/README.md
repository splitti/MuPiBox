# MuPiBox Classic documentation source

The Classic pages served at https://docs.mupibox.de/classic/ are authored here, **in MuPiBox Classic**.

- Index: docs/site/classic/{de,en,es,fr}/index.md
- Navigation: docs/site/classic/pages.json

The common static site theme and generator live in the NG site deployment infrastructure, but the Classic content and edit links belong only to this repository. The NG documentation build reads this directory as an **external, read-only source**.

Existing detailed Classic guides: https://mupibox.de/anleitungen/classic/
